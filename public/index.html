Interpretation limits

These are communication indicators, not proof of attraction, love, honesty, attachment style or intent. OCR can miss or misread content. Screen-recording playback time is not original message time, so response latency cannot be inferred reliably.

Privacy by design

  • Video OCR and basic analysis run in your browser using Tesseract.js.
  • Local OCR and basic metrics run in your browser. If you choose AI analysis, only the corrected transcript is sent securely to the configured AI service through the site server function. Video files are not sent.
  • Use only chats you have permission to analyse. Avoid sharing reports containing private information.
